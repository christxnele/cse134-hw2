MathML

Einstein's mass-energy equivalence written in MathML:

E = m c 2

Developers couldn't rely on MathML because browser support was inconsistent. Firefox and Safari supported it early on, but Chrome only supported it briefly in version 24 before removing it. Since most people use Chrome, most users couldn't see MathML rendered, leading developers to use images or JavaScript libraries like MathJax instead. This changed in January 2023, when Chrome 109 added MathML support back, making it usable across all major browsers.
